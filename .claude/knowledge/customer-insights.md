## How to Use This File

### During Roadmap Planning
- Check "Top Feature Requests" for validated demand
- Reference "Recurring Pain Points" for prioritization
- Review "Product-Market Fit Signals" for strategic direction

### During PRD Writing
- Cite specific customer evidence from this file
- Link pain points to personas
- Reference competitive intelligence for context

### During CS Monthly Reviews
- Add new patterns discovered
- Update frequency counts on existing patterns
- Archive resolved pain points

### During Sprint Documentation Reviews
- Check if released features addressed documented pain points
- Update customer insights based on feature adoption
- Note new patterns that emerge from new capabilities
