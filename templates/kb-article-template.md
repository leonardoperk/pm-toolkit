## Content Guidelines When Filling This Out

**Tone:**
- Professional but friendly
- Confident and helpful
- Use "you" perspective
- Avoid technical jargon

**Structure:**
- Keep paragraphs short (2-3 sentences max)
- Use bullet points and numbered lists
- Add bold for emphasis on key terms
- Include actual UI text in quotes ("Click 'Save'")

**Screenshots:**
- Mark where screenshots should go: `[Screenshot: Description of what to show]`
- Screenshots should show the happy path, not errors
- Annotate screenshots with arrows/highlights if needed

**Testing:**
- Test every instruction yourself before publishing
- Have someone unfamiliar with the feature try to follow it
- Update based on support tickets (common confusion points)

**Updates:**
- Review quarterly or when feature changes
- Add new FAQ items based on support questions
- Keep troubleshooting section current
